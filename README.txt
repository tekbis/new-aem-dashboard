AEM BAKERY DASHBOARD — DEMO

A stand-alone demo of the owner dashboard to show the client. It is NOT connected to the website or any database.
Everything works (orders, products, website text, settings), with sample orders. Changes are saved only in the
browser being used, so each viewer starts from the same demo.

Deploy on Netlify: app.netlify.com > Add new site > Deploy manually > drag this folder (the one with index.html).
